# Teste de Conhecimento 1

Resolução do Teste de Conhecimento 1 (Fundamentos Matemáticos) da disciplina Matemática Aplicada à Computação — Unifap 2026.2.

O notebook analisa os custos mensais de transporte de uma empresa de comércio eletrônico: gráfico de dispersão dos dados, ajuste de uma função afim f(x) = ax + b e previsão dos custos dos meses 13, 14 e 15.

## Arquivos

- `Teste_de_Conhecimento_1.ipynb` — código, gráficos, respostas das etapas e conclusão
- `base_custos_transporte.csv` — base de dados utilizada no notebook

## Como executar

Abra o notebook no Google Colab ou no Jupyter com o arquivo CSV na mesma pasta (no Colab, envie o CSV pela aba Arquivos) e execute todas as células. Bibliotecas: pandas, numpy e matplotlib.
